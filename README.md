# Bili2Media

Bili2Media 是一款本地 Android 应用，可将 哔***哩 缓存的媒体导出为 MP4、M4A 或 MP3。

不联网、**无广告**

**如果您也在使用，并且存在需求和问题，请反馈给作者（比心）**

安装包下载地址：

[download](https://github.com/Cillebokin/Bili2Media/releases)

## 使用方式

- 默认输入目录：`Download/Bili2Media/Input`
- 默认输出目录：`Download/Bili2Media/Output`
- 在主界面选择 MP4、M4A 或 MP3 导出；设置中可调整输入/输出目录和 MP3 码率。

> 应用无法直接读取 哔***哩 的缓存目录。请将待转换的缓存文件手动复制到输入目录，或在设置中选择其他可访问的目录。
